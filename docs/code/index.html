Vectorial capacity uncertainty tool

Interactive tool that propagates uncertainty in mosquito mortality and transmission parameters through an age-specific vectorial capacity model, giving a distribution of Ct and a sensitivity ranking. Runs in your browser with R and Shinylive, so no data leaves your computer. Checked against Styer et al. (2007).

RShinyliveModeling

Locoweed volatiles: data and analysis

Data and analysis code for a study of volatile organic compound profiles in white locoweed (Oxytropis sericea) with and without the endophytic fungus Alternaria oxytropis. Includes raw spreadsheets, processing notebooks, and R scripts that reproduce the PERMANOVA, PCA, SIMPER and mixed-model results in the manuscript.
