My code & data

Analysis code, data and small tools from my own research.

Vectorial capacity uncertainty tool

R · Shinylive · Modeling

An interactive tool showing how uncertainty in mosquito mortality and transmission affects vectorial capacity, and which parameters matter most. Runs in your browser with R and Shinylive, so no data leaves your computer. Validated against Styer et al. (2007).

github.com

Locoweed volatiles: data and analysis

R · Reproducible research · Chemical ecology

Data and analysis code for a study of volatile compounds in white locoweed (Oxytropis sericea) with and without its fungal endophyte, Alternaria oxytropis. Includes raw data, notebooks, and the R scripts that reproduce the manuscript’s results.

github.com
